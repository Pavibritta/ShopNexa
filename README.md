🛍️ ShopNexa – React Shopping App

A modern React-based shopping application where users can browse products, add items to cart, manage quantities, and place orders with a QR payment option.

This project demonstrates React concepts like Context API, state management, reusable components, and responsive UI design using Tailwind CSS.

🚀 Features

✅ Product listing page
✅ Add to Cart functionality
✅ Cart modal with quantity control
✅ Order summary with total price
✅ QR code payment simulation
✅ Place order alert confirmation
✅ Form validation for login
✅ Responsive UI with Tailwind CSS

🖥️ Tech Stack

React.js

Context API

Tailwind CSS

JavaScript (ES6+)

QR Code Generator (qrcode.react)
